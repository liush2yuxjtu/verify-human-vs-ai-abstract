# 学术摘要五步清单

用于**结构面**。对人写（H）与 AI（A）每一步标：`有` / `弱` / `无`。更多步为「有」且不堆未定义缩写时，结构偏向 H。

模式来源：Missing NLP Paper Guide（abstract）、MIT EECS Communication Lab、常见 *ACL / ML 会议建议。

| # | 步骤 | 算「有」的标准 |
|---|---|---|
| 1 | 背景 / 缺口 | 具体问题 + 现有做法缺什么（不是「近年 X 进展很快」空话） |
| 2 | 本文动作 | 清楚写出 we propose / introduce … 并点名产物 |
| 3 | 方法 | 非专家能懂的做法；避免公式堆、未解释缩写 |
| 4 | 结果 | 至少有一个具体数字或清晰定性结果，且不要只埋在最后一句 |
| 5 | 启示 | 领域该带走什么（范式、能力、带局限意识的贡献） |

可选诚实补句（喂给声明诚实面，不算结构）：结果参差时写清局限或范围。

## 常见翻车

- 空泛开场 → 第 1 步弱
- 只写方法 → 第 1/5 步无
- 把 headline 数字埋到最后 → 第 4 步弱
- 「我们还做了消融」却不说发现了什么 → 不算结果
